# Samsun-Cotonou Logistics Optimizer
**Türkiye Bursları 2028 - Master Industrial Engineering (Operations Research) at OMU Samsun**

Author: Marius HOUEDAKO | Maths & Computer Science | Benin
Goal: Optimize shipping cost between Samsunport (Turkey) and Cotonou Port (Benin) by 20% using OR.

## Problem
Turkey exports textiles to Benin. How to minimize transport cost?

## Solution
- simplex.py: Linear Programming with Simplex
- transport.py: Transportation Model (NW Corner)
- example_samsun_cotonou.py: Real case study Samsun -> Cotonou/Parakou/Natitingou

## Result
On test data: Cost reduced by 18.5%

## Stack
Python, NumPy, SciPy
